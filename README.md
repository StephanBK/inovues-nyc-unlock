# One hospital unlocks a city — visual options

Open `index.html` for the launcher. Same setup as before:
1. `config.js` → paste your Mapbox public token (already done if you kept the file).
2. `python3 -m http.server 8080` in this folder → http://localhost:8080
3. GitHub Pages: push folder, Settings → Pages → main / root.

Options: `ripple.html` (1), `constellation.html` (3, no token needed), `scenes.html` (4), `hybrid.html` (5). `original.html` is the first version.
Keys: → / Space advance, ← back. Shared code: `shared.js` (palette, data, constellation renderer), `shared.css`, `buildings.json`, `agg.json`.
